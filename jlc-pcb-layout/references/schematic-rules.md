# 原理图设计规则（Schematic Rules）

面向**可制造、可调试、可维修**的原理图。每一条都尽量给判据和数值来源；给不出判据的，明说"这是经验，不是规则"。

规则号约定：`SCH-<语义>`。已自动化的在 `scripts/schem.py erc` 里实现，见 §9 总表。

---

## 1. 三条硬约束

### 1.1 网络名是唯一身份，不是标签

网表、DRC、PCB 网络列表三处共用同一个字符串。名字写错不会报错，只会**悄悄变成两个网络**（原理图上看着连着，PCB 上没连）或者**悄悄并成一个网络**（本该隔离的两个地短在一起）。

- 只允许 `A-Za-z0-9_+-/.`，长度 ≤32。
- 不用 `NC` / `DNC` / `NONE` 当网络名——这些在部分工具里是保留字，会被当成"不连接"。
- 电源网络统一前缀：`VIN` / `5V` / `3V3` / `VBUS`。不要同一路电出现 `VCC`、`VDD`、`+3.3V`、`3V3` 四种写法（`SCH-NET-NAME`）。
- 跨页连接一律用网络标签，不要靠"画到同一根线上"——页内连线出了本页就断了。
- 地种类 ≤2 种（模拟/数字各一，或单一 GND）。每多一种地就多一个"单点汇合在哪"的问题，而这个问题十次有八次没人回答（`SCH-GND-KINDS`）。

### 1.2 每个引脚必须有确定电平

"悬空"在数字电路里不是中间态，是**随机态**。上电瞬间它可能被读成任意值，而 MCU 的初始化代码还没跑起来。

必须处理的引脚：`NRST`、`BOOT0`/`BOOT1`、片选 `CS`、使能 `EN`、总线方向 `DE/RE`、中断输入、未使用的运放输入。

判据：该网络至少 2 个引脚，或者 1 个引脚但明确标了测试点（`TP_` 前缀）。单引脚网络一律报 `SCH-ERC-SINGLE`。

### 1.3 器件极性在图上看不出来时，用丝印和图注补

原理图符号的阳极/阴极、正负端、1 脚方向，必须与封装、丝印、BOM 三处一致。电解电容与钽电容反接会炸（钽电容反接是**起火**级别，不是"不工作"）。

## 2. 电源树

### 2.1 三级电容各司其职

| 层级 | 位置 | 取值 | 作用 | 省了的后果 |
|---|---|---|---|---|
| bulk | 每路电源入口 1 颗 | ≥10µF 陶瓷/钽 | 储能、扛负载阶跃 | 大电流瞬变时电压塌陷，MCU 复位 |
| 去耦 | **每个** IC 的**每个**电源脚 1 颗 | 100nF X7R/X5R | 提供高频回流路径 | 高频噪声走电源平面，EMC 与误动作 |
| 高频 | 敏感芯片旁可选 | 1~10nF | 抑制 >100MHz | 一般项目可省，射频/高速必加 |

判据（`SCH-PWR-DECOUPLE` / `SCH-PWR-BULK`）：

- 每颗 IC/MCU 的每个电源引脚，到地之间必须有容量 ≥100nF 的电容。
- 每路电源（不含外部输入 `VIN_IN`/`VBUS`，那一路的储能责任在源端）总电容 ≥10µF。
- 陶瓷电容**电压额定 ≥2× 工作电压**：X7R 在额定电压下容值会掉 30~70%，5V 电路用 6.3V 电容是自欺欺人。

### 2.2 电源树的顺序不能反

```
输入保护（保险 + TVS） → buck（大压差/大电流） → LDO（低噪声/小电流） → 负载
```

压差大还用 LDO，功耗全变热：`Pd=(Vin−Vout)×Iout`。24V→3.3V @0.3A 就是 6.2W，SOT-223 封装（θja≈100℃/W）结温直接飙到 600℃+ —— 这不是"偏热"，是**这个组合物理上不成立**。用 `schem.py calc ldo` 先校核，`TOO_HOT` 就改 buck。

LDO 的效率上限就是 `Vout/Vin`。20% 的效率意味着 80% 的电能变成热，任何散热设计都救不回来。

### 2.3 上电顺序

多路电源的板上电顺序由芯片手册决定（很多 FPGA/SoC 要求 core 先于 IO）。没有要求时，让**电压高的先起**（buck 先于 LDO），避免后级芯片的 IO 通过 ESD 二极管倒灌前级。

## 3. 复位与时钟

### 3.1 复位

最小可用复位：`10k 上拉到电源 + 100nF 到地`。RC 时间常数 τ=1ms，3τ≈3ms，足够覆盖普通电源的上升时间。

- 电源上升慢（>10ms，大电容或热插拔）时，RC 复位会失效——芯片在电源还没稳时就结束复位。改用专用复位芯片（如带延迟的 supervisor）。
- 复位按钮要与复位电容**并联**，不是串联。
- `BOOT0` 也必须给确定电平，不能悬空。悬空时芯片可能进不了正常启动模式，这种故障极难查。

### 3.2 晶振

负载电容：`C1 = C2 = 2×(CL − Cstray)`

- `CL` 是晶振手册给的负载电容（常见 8/10/12pF）。
- `Cstray` 是 PCB 走线 + 芯片引脚寄生电容，2 层板取 3pF，4 层以上取 5pF。
- 例：CL=12pF、Cstray=3pF → C1=C2=18pF。
- 两侧电容**必须同值**，不等会造成频偏和起振裕量不足（`SCH-XTAL-CL`）。
- 晶振体到 MCU 的距离在 PCB 上有硬要求（≤300mil，见 `layout-rules.md` TY-7.2.2），原理图阶段先把网络拉短。

用内部 RC 振荡器时，把 `XTAL_IN`/`XTAL_OUT` 从网表里删掉，否则 ERC 会一直问"晶振在哪"（`SCH-MCU-CLOCK`）。这是**故意的**——让"用内部时钟"成为一个明确决定，而不是忘了画。

## 4. 接口

### 4.1 USB Type-C 受电（UFP）

**CC1 和 CC2 必须各接一颗 5.1kΩ±5% 下拉到 GND**。这是 Type-C 规范里 source 识别"有设备插入"的唯一依据，缺一颗就有一半的插线方向不供电——而用户会认为是"板子坏了"。

- 只做受电（UFP）时**不要放 Rp**。放了设备变成 DRP，source 的行为不可预期。
- D+/D− 串 0~22Ω，并在连接器侧就近加 ESD 阵列（USBLC6 类）。
- VBUS 至少 1µF。
- 判据 `SCH-USB-CC`（FAIL 级）：CC 网络没有 5.1k±5% 下拉即失败。

### 4.2 RS485

- 终端电阻 **120Ω，只在总线两端各一颗**。中间节点加了会把总线负载压垮，通信距离骤降。
- 失效保护偏置：`A` 经电阻上拉到 Vcc，`B` 经电阻下拉到 GND，保证空闲时 `Vab ≥ 200mV`（TIA-485-A 的接收门限）。整条总线只需**一处**偏置，每个节点都加会互相打架。
  - 偏置上限：`Rb ≤ Rt×(Vcc/0.2 − 1)/2`。5V/120Ω → 1440Ω，实用取 560~1kΩ。
- 总线入口加 TVS，共模范围 −7~+12V。
- `DE`/`RE` 并在一起做方向控制，不接 MCU 时必须下拉到收态（否则上电瞬间可能总线上乱发）。

### 4.3 CAN

- 终端 **120Ω，同样只在两端**。
- 推荐**分裂终端**：两个 60Ω 串联，中点经 4.7nF 到地。好处是给共模噪声一条低阻泄放路径，EMC 明显好于单个 120Ω。
- 收发器 VCC 必须与 TXD/RXD 电平匹配。3.3V MCU 配 5V 收发器时，TXD 高电平可能不够（看收发器 VIH），要么选 3.3V 兼容型号，要么加电平转换。

### 4.4 I2C

上拉电阻是**算出来的**，不是抄 4.7k：

- 下限由灌电流决定：`Rmin=(Vcc−VOL)/IOL`。3.3V、VOL=0.4V、IOL=3mA → 967Ω。
- 上限由上升时间决定：`tr ≈ 0.847×R×Cb`，`Rmax = tr_max/(0.847×Cb)`。
  - 100kHz（标准模式）tr≤1000ns，Cb=200pF → Rmax≈5.9kΩ
  - 400kHz（快速模式）tr≤300ns，Cb=200pF → Rmax≈1.8kΩ
- 候选区为空说明总线电容太大或速率太高：降速、缩短总线，或换主动上拉。

用 `schem.py calc i2c` 直接出区间。**4.7k 只适合 100kHz 短总线**，400kHz 长线用 4.7k 是最常见的 I2C 调不通原因之一。

### 4.5 UART

- 跨设备时 TX/RX 必须交叉（本板 TX → 对端 RX）。
- 长线或跨板：串 22~100Ω 抑制振铃，接收端加 TVS。
- 调试口留出 GND 针，只留 TX/RX 两根线的调试口在示波器上没法测。

## 5. 驱动

### 5.1 继电器

```
MCU GPIO → 基极限流电阻 → 三极管基极
三极管集电极 → 继电器线圈 → 电源
线圈两端反并联续流二极管（阴极接电源侧）
基极对地加下拉电阻
```

- `Ic ≥ 3×线圈电流`（饱和余量）。
- `Ib = Ic/(β_min) × 3`，`Rb = (Vdrive − Vbe)/Ib`。β 用**最小值**，不是典型值。
- **续流二极管不能省**（`SCH-RELAY-FLYBACK`，FAIL 级）。线圈是电感，关断瞬间 `V=L·di/dt` 会到几百伏，直接打穿三极管。
- 基极下拉不能省：MCU 上电复位期间 GPIO 是高阻，没有下拉就可能误导通，表现为"上电瞬间继电器啪一声"。
- 触点侧驱动感性负载（电磁阀/电机）时，还要在触点两端加 RC 吸收或压敏电阻，否则触点拉弧、寿命骤降。

### 5.2 MOSFET 低边开关

- 栅极串 10~100Ω 抑制振荡，并加 10k 下拉给确定电平。
- `Vgs(th)` 要明显低于驱动电压（3.3V 驱动选逻辑电平管，`Vgs(th)` ≤1.5V），`Vgs_max` 要高于驱动电压。
- 感性负载另加续流；容性负载要核算浪涌电流与 SOA。

### 5.3 蜂鸣器

有源蜂鸣器给直流就响；无源蜂鸣器必须给 PWM（方波频率决定音调）。**驱动方式完全不同，选型时必须问清楚**——这是需求澄清里最容易漏的一条。

## 6. 保护

### 6.1 TVS

- `VRWM ≥ 1.1×工作电压`。等于工作电压都不行：24V 系统用 SMBJ24A，正常工作时就在击穿边缘漏电发热（`SCH-TVX-VRWM`，FAIL 级）。
- 钳位电压 `VC` 必须低于被保护器件的**绝对最大额定值**。这条 ERC 查不了（需要料号手册），必须人工核对。
- 24V 工业输入的常见组合：SMBJ33A/36A + 后级 buck 耐压 ≥40V。用 30V 档时要确认后级绝对最大值 >48V。

### 6.2 保险与防反接

- 保险额定电流取整板最大电流的 1.5~2 倍。
- 自恢复保险（PTC）响应慢，扛不住雷击浪涌，但能防持续过流与短路；要抗浪涌得靠 TVS。
- 防反接三选一：串联肖特基（压降 0.3~0.5V）、PMOS 理想二极管（压降小、成本高）、整流桥（压降 2×，只适合小电流）。

### 6.3 ESD

外部可触摸的连接器（USB、RS485、按键、调试口）都要在**靠近连接器**的位置放 ESD 器件。放在芯片旁边等于让浪涌先穿过整块板。

## 7. ADC 前级

- SAR ADC 的采样保持电容需要被快速充电。**源阻抗 ≤10kΩ** 是 12 位精度下的经验上限（`SCH-ADC-IMP`）。
- 分压后并 100nF：既是电荷缓冲，也是抗混叠的最简形式。
- 分压电流 ≥10µA 才有抗噪余量。为了省电把上臂做到 1MΩ，噪声会盖掉信号。
- 分压电阻的精度直接用 1% 的；5% 电阻做测量，误差预算一开始就不够。

## 8. 图面与命名

- **位号**：`U`（IC）、`R`、`C`、`L`、`D`（二极管/LED/TVS 统一 D）、`Q`、`Y`（晶振）、`J`（连接器）、`F`（保险）、`K`（继电器）、`SW`、`BZ`、`TP`。
- 一个功能块画在一起，块与块之间留白。别让电源和高速信号在图面上交织。
- 电源网络用网络标签，不要画长线跨越整页。
- 每页右下角标注：页名、版本、日期、设计者。多页工程加一页"页索引"。
- 图注里写清反向标注：稳压器的输出电压/电流、晶振频率、连接器用途。

## 11. 什么时候该停手问人

1. 客户给的功能描述里，**接口电气标准没定**（RS485 还是 RS232？4~20mA 还是 0~10V？）——标准不同，保护与隔离方案完全不同。
2. 需要**隔离**（隔离 RS485/CAN/电源）但没给隔离电压等级。
3. 电源电流估算不出来（客户说"差不多 1A 吧"）。
4. 涉及**安规**（市电输入、医疗、车载认证）。
5. 客户指定的器件在立创商城**没货或已停产**。
6. 需求里出现互相冲突的约束（要小、要便宜、要工业级、要一周交付）。

这六种情况停下来问，比按假设画完再返工便宜一个数量级。
