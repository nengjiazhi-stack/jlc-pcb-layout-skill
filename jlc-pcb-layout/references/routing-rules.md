> 出处：`TY-` 华为/通用规范，`EM-` 艾默生工艺规范，`BELL-` 上海贝尔，`ASUS-` 华硕。数值真源在 `assets/constraints.json`。

- 国内推荐最小线宽/间距：**0.25mm / 0.3mm**（4mil/4mil 是极限档）；
- 国际极限：4mil/6mil、2mil/2mil；
- 嘉立创打样：最小 4mil/4mil（超出需工艺评审）。

## 2. 电气间距（安规）

按"一次侧 / 二次侧"和"输入电压档"查表。**爬电距离 > 空气间隙时以爬电距离为准**。

一次侧（输入 150–300V 档）：

| 工作电压 | 空气间隙 | 爬电距离 |
|---|---|---|
| 50V | 1.0mm | 1.2mm |
| 150V | 1.4mm | 1.6mm |
| 200V | — | 2.0mm |
| 250V | — | 2.5mm |
| 300V | 1.7mm | 3.2mm |
| 400V | — | 4.0mm |
| 600V | 3.0mm | 6.3mm |

二次侧：71V → 0.7/1.2；125V → 0.7/1.5；150V → 0.7/1.6；200V → 0.7/2.0；250V → 0.7/2.5（mm）。

一次侧线到保护地：150–300V 表取 4.0mm，300–600V 表取 6.3mm。
裸露的不同电压焊接端子之间保证 **最小 2mm** 安规距离（EM-5.9.13）。

命令：`python rules.py clearance --voltage 300 --side primary`

## 3. 过孔

### 3.1 孔径与板厚

| 板厚 | 最小孔径 |
|---|---|
| 3.0mm | 24mil |
| 2.5mm | 20mil |
| 2.0mm | 16mil |
| 1.6mm | 12mil |
| 1.0mm | 8mil |

孔厚比 ≤ 5~8（TY），EM 口径 ≤1:6。

### 3.2 优选系列（孔径 / 焊盘 / 内层热焊盘）

24/40/50 mil，20/35/45，16/28/40，12/25/35，8/20/30。

EM 标准过孔（内径/外径）：12/25、16/30、20/35、24/40、32/50 mil。

### 3.3 特殊要求

- BGA 下方导通孔孔径 12mil，且**正反两面须盖阻焊**（EM-5.6.2 / BELL-16）；
- SMT 焊盘边缘到导通孔边缘 ≥10mil；过孔塞绿油时 ≥6mil（EM-5.6.3）;
- SMT 器件焊盘上不允许有导通孔（散热用 DPAK 焊盘除外）（EM-5.6.4）；
- 过波峰焊的板，若元件面有贴片器件，其底下不能有过孔或过孔要盖绿油（EM-5.6.6）；
- 测试孔：孔径不限，焊盘 ≥25mil，中心距 ≥50mil（TY）。

命令：`python rules.py via --thickness 1.6`

## 4. 层与平面

| 规则 | 内容 | 出处 |
|---|---|---|
| 电源/地相邻 | 电源层与地层尽量靠在一起，中间不安排布线 | TY-6.3.1.1 |
| 层间正交 | 相邻布线层的走线方向取垂直，减少层间串扰 | TY-6.5.6.4 / BELL-6 |
| 参考平面 | 所有布线层尽量靠近一个平面层，优选地平面作隔离层 | TY-6.3.1.1 |
| 平面分割宽度 | 电位差 >12V → 50mil；≤12V → 20~25mil | TY-6.3.1.2.5.3 |
| 20H | 电源层相对地层内缩 20H 可限制 70% 电场，100H 限制 98% | TY-6.5.6.19 |
| 3W | 线中心距 ≥3 倍线宽保持 70% 电场不互扰；10W 达 98% | TY-6.5.6.18 |
| 电源层重叠 | 不同电源层在空间上避免重叠，难以避免时间隔地层 | TY-6.5.6.17 |
| 平面完整性 | 导通孔密集区注意不要挖断平面形成分割 | TY-6.5.6.16 |
| 五—五规则 | 时钟 ≥5MHz 或上升时间 <5ns → 必须多层板 | TY-6.5.6.20 |

平面被高速信号回流路径破坏时，应在布线层用接地铜箔把该网络包围，给出地回路（TY-6.3.1.2.5.3 C）。

## 5. 走线二十条（TY-6.5.6，原文规则名 + 执行口径）

> 引用约定：本文与 `check.py` 用 `TY-6.5.6-<n>` 指向下表的第 n 条（例：`TY-6.5.6-12` = 倒角、`TY-6.5.6-18` = 3W）。

| # | 规则 | 执行口径 |
|---|---|---|
| 1 | 地线回路 | 信号与其回路的环面积最小；双层板把剩余区域用参考地填充并打过孔缝合 |
| 2 | 串扰控制 | 加大平行间距，遵循 3W；平行线之间插入接地隔离线；减小布线层到地平面距离 |
| 3 | 屏蔽保护 | 时钟/同步/高频信号上下左右用地线隔离，屏蔽地要有效接到实际地平面 |
| 4 | 走线方向 | 相邻层正交，禁止相邻层同向长距离平行 |
| 5 | 开环检查 | 不允许一端浮空的走线（天线效应） |
| 6 | 阻抗一致 | 同一网络线宽全程一致；不可避免的变宽（连接器/BGA 出线）要把不一致段压到最短 |
| 7 | 终结匹配 | 延迟 > 上升时间 1/4 即按传输线处理：点对点用源端串接或终端并接；菊花链用终端并接；星型参考点对点 |
| 8 | 闭环检查 | 禁止信号在不同层间形成自环 |
| 9 | 分枝长度 | Tdelay ≤ Trise/20 |
| 10 | 谐振 | 布线长度不得与信号波长成整数倍 |
| 11 | 短线 | 关键信号（时钟）务必最短，振荡器紧靠器件 |
| 12 | 倒角 | 禁止锐角/直角，一律 45°（或圆弧）转折 |
| 13 | 去耦 | 去耦电容紧靠电源脚；双层板让电流先经滤波电容再进器件 |
| 14 | 分区/分层 | 高频部分靠近接口布置，高低频地平面分割后在接口处单点相接 |
| 15 | 孤立铜区 | 孤铜接地或删除，不留悬空铜块 |
| 16 | 平面完整 | 见 §4 |
| 17 | 电源层重叠 | 见 §4 |
| 18 | 3W | 见 §4 |
| 19 | 20H | 见 §4 |
| 20 | 五—五 | 见 §4 |

## 6. 电源与地（BELL-19 的实操口径）

- 尽量给出**独立的电源层和地层**；即使表层拉线，电源线和地线也要尽量短、足够粗。
- 多层板一般都有电源层与地层；**模拟部分与数字部分的地和电源即使电压相同也要分开**。
- 单/双层板：电源线与地线尽量粗而短，可按 **1mm 线宽 ≈ 1A** 估算，电源和地构成的**环路尽量小**。
- 防止电源线较长时耦合杂讯直接进入负载：应在**进入每个器件之前**先做电源去耦，且每个负载独立去耦、先滤波再进负载。

> 注意"1mm≈1A"是经验速算（1oz），不等于规范表。3A 以上务必查表：`rules.py width --current 3`。

## 7. 差分类信号（补充口径）

- 对称：两条线的长度、过孔数、拐角数量尽量一致，P/N 换层必须同时换；
- 间距恒定：差分间距全程保持，不要在过孔处摊开；
- 参考平面连续：差分对下方不得跨越平面分割，换层时在过孔旁补地过孔；
- 偏斜：等长组内偏差按协议要求控制（USB2.0 常见 ≤50mil，具体看协议），用 `easyeda pcb report` 读实际长度与 skew。

## 8. 测试点与丝印

**测试点**（TY-6.7.2 / EM-5.12 / BELL-24）：

- ICT 焊盘 ≥24mil(0.6mm)，两单独测试点中心距 ≥60mil(1.5mm)；
- 探针节距按 2.54mm 布置，测试点优先放焊接面；
- 每个网络至少一个可探针的测试点，电源和地各留 ≥10 个均匀分布的测试点；
- 距离板边 >125mil；测试点加线尽量短，优先"串在走线上"而不是拉分支；
- 密度不大于 5 个/cm²，均匀分布。

**丝印**（EM-5.8）：

- 字符遵循**从左至右、从下往上**；极性件在每个功能单元内方向一致；
- 丝印不得压在焊盘/导通孔上，丝印间距 >5mil；
- 所有器件、安装孔（H1…Hn）、定位孔都要有丝印标号，器件位号不得被安装后遮挡；
- 丝印字符必须与 BOM 一致；
- 保险丝附近需 6 项完整标识（保险丝序号、熔断特性、额定电流、防爆特性、额定电压、英文警告语）；
- 危险电压区域用 40mil 宽虚线与安全区隔离，并印高压警示（EM-5.9.2）。

## 9. 布线自检清单

1. 每个网络的线宽是否来自 `rules.py`（而不是拍的）？
2. 电源/地环路面积是否最小，去耦是否在负载之前？
3. 关键信号（时钟、差分、复位、模拟小信号）是否优先、最短、有完整参考平面？
4. 是否有直角/锐角、悬空线头、自环、孤铜？
5. 相邻层是否正交，3W 是否满足？
6. 差分对是否对称、等长、参考平面连续？
7. 平面分割宽度是否按电位差取值，是否有跨分割的高速信号？
8. 过孔尺寸与板厚比例是否合规，BGA 下是否 12mil 且盖阻焊？
9. 测试点是否覆盖每个网络，位置是否可探？
10. 丝印是否压焊盘、极性是否可辨？
