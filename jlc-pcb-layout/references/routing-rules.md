## 6. 电源与地（BELL-19 的实操口径）

- 尽量给出**独立的电源层和地层**；即使表层拉线，电源线和地线也要尽量短、足够粗。
- 多层板一般都有电源层与地层；**模拟部分与数字部分的地和电源即使电压相同也要分开**。
- 单/双层板：电源线与地线尽量粗而短，可按 **1mm 线宽 ≈ 1A** 估算，电源和地构成的**环路尽量小**。
- 防止电源线较长时耦合杂讯直接进入负载：应在**进入每个器件之前**先做电源去耦，且每个负载独立去耦、先滤波再进负载。

> 注意"1mm≈1A"是经验速算（1oz），不等于规范表。3A 以上务必查表：`rules.py width --current 3`。

## 7. 差分类信号（补充口径）

- 对称：两条线的长度、过孔数、拐角数量尽量一致，P/N 换层必须同时换；
- 间距恒定：差分间距全程保持，不要在过孔处摊开；
- 参考平面连续：差分对下方不得跨越平面分割，换层时在过孔旁补地过孔；
- 偏斜：等长组内偏差按协议要求控制（USB2.0 常见 ≤50mil，具体看协议），用 `easyeda pcb report` 读实际长度与 skew。

## 8. 测试点与丝印

**测试点**（TY-6.7.2 / EM-5.12 / BELL-24）：

- ICT 焊盘 ≥24mil(0.6mm)，两单独测试点中心距 ≥60mil(1.5mm)；
- 探针节距按 2.54mm 布置，测试点优先放焊接面；
- 每个网络至少一个可探针的测试点，电源和地各留 ≥10 个均匀分布的测试点；
- 距离板边 >125mil；测试点加线尽量短，优先"串在走线上"而不是拉分支；
- 密度不大于 5 个/cm²，均匀分布。

**丝印**（EM-5.8）：

- 字符遵循**从左至右、从下往上**；极性件在每个功能单元内方向一致；
- 丝印不得压在焊盘/导通孔上，丝印间距 >5mil；
- 所有器件、安装孔（H1…Hn）、定位孔都要有丝印标号，器件位号不得被安装后遮挡；
- 丝印字符必须与 BOM 一致；
- 保险丝附近需 6 项完整标识（保险丝序号、熔断特性、额定电流、防爆特性、额定电压、英文警告语）；
- 危险电压区域用 40mil 宽虚线与安全区隔离，并印高压警示（EM-5.9.2）。

## 9. 冗余走线判据（RT-*）

### 9.1 为什么要有这一节

`drc-check` 查间距/短路/未布通，`check` 查悬空端/酸角/孤铜——**两者都查不出"多出来的铜"**：

- 重复段：两段同一网络的铜压在同一个位置，不短路、不开路，电气完全合法；
- 残段：走一半改道留下的尾巴，长度不够就只是个"悬空线头 WARN"；
- 自环：闭合回路在电气上是并联，DRC 视而不见；
- 绕行：连得通、间距够，只是多走了两倍路。

它们的共同成因是「改线时在旧线上叠新线」。EDA 不会自动合并同网络重叠段，也没有 undo，所以必须有一层只读的几何判据把它们列出来。

### 9.2 四条判据

阈值全部在 `assets/constraints.json` → `trace_redundancy`，代码里不写死。

| 规则号 | 判据 | 阈值字段 | 默认 | 默认级别 | 对应条款 |
|---|---|---|---|---|---|
| `RT-DUP-01` | 同层同网，两段夹角 ≤3°、垂距 ≤1.5mil（共线），投影重叠 ≥ 较短段的 80%，且两段都 ≥20mil | `collinear_angle_deg` / `collinear_tol_mil` / `dup_overlap_ratio` / `dup_min_len_mil` | 3° / 1.5mil / 0.8 / 20mil | FAIL | DFM 的 Duplicate Trace / Sliver；TY-6.5.6-15 精神 |
| `RT-STUB-02` | 从自由端（不在焊盘/过孔上、也不是岔路口）沿铜走到第一个岔路口或锚点，累计长度超阈值 | `stub_min_len_mil` / `stub_min_len_factor` | 200mil / 10×线宽 | FAIL | TY-6.5.6-5 开环的强化 |
| `RT-LOOP-03` | 同层同网，加边时两端已连通（生成树闭合）→ 闭合铜环，周长按最短路 + 闭合边算 | `loop_min_perimeter_mil` | 50mil | WARN | TY-6.5.6-8 闭环 |
| `RT-DETOUR-04` | 该网络生成树铜长 / 引脚坐标的曼哈顿最小生成树 | `detour_ratio` / `detour_ratio_high_speed` / `high_speed_patterns` | 1.8 / 1.3 | WARN | TY-6.5.6-9 分枝长度、TY-6.5.6-1 回路面积 |

几条实现上的取舍，改代码前先读：

- **残段按"尾巴累计"算，不按单段算**。残段常是两三段接起来的，只看单段就漏。所以先把"端点落在别的段内部"的位置切开，让 T 接成为图上的真节点。
- **重复段只算一次**。检测到重叠后，把较短的那段从图上摘掉再做环/长度计算，否则重复段会立刻被当成环，一个缺陷报两次。
- **绕行用生成树长度，不用总铜长**。总铜长会把闭合边重复计入，导致"有环"的网络必然同时报绕行；用生成树后，两个判据各说一件事：`RT-LOOP-03` 说形状错，`RT-DETOUR-04` 说代价。
- **长残段不再重复报 `TY-6.5.6-5`**。超过阈值的残段由 `RT-STUB-02` 报 FAIL，短尾巴才留在 WARN 里。
- **判据不认意图**。测试点引线、天线焊盘、蛇形等长、差分补偿都会被误判，见 9.3。

### 9.3 白名单：`allow`

```json
"trace_redundancy": {
  "allow": [
    {"net": "TP_*", "rules": ["RT-STUB-02"], "max_len_mil": 400,
     "reason": "测试点引线按设计保留，长度受探针间距限制"},
    {"net": "ANT", "rules": ["RT-STUB-02", "RT-DETOUR-04"],
     "reason": "天线馈点，电路径本身就是匹配结构的一部分"}
  ]
}
```

规则：

1. `net` 用 glob（`*` 通配），`rules` 省略表示该网络的所有 RT 规则；
2. `max_len_mil` 是**豁免上限**——超过照报。没有它，登记一次就永久静音；
3. 每条登记必须有 `reason`，且会以 `RT-ALLOW` INFO 出现在检查结果里，**必须抄进交付物的「允许保留的冗余」**；
4. 不要用 `"net": "*"` 图省事。那等于把四条判据全关掉，比不装还危险。

### 9.4 数据不足时的行为

| 情况 | 行为 |
|---|---|
| 快照里没有任何焊盘坐标 | `RT-STUB-02` 不参与判定（缺数据已由 `FAB-DATA` UNKNOWN 报出，不重复记） |
| 某个网络自己没有焊盘/过孔坐标 | 该网络报 `RT-STUB-02` UNKNOWN，不编 FAIL |
| 网络只有一个引脚 | `RT-DETOUR-04` 跳过（算不出参考长度） |
| 网络有引脚但没有走线 | 全部跳过（未布线，不是冗余） |

**UNKNOWN 不是通过。** 看到它就补数据重跑。

### 9.5 过程对账：按 primitiveId 记账（`RT-JRN-*`）

9.2 的四条判据只看铜，有三种"多余"它抓不到：

| 形态 | 几何判据为什么不报 |
|---|---|
| 新线只盖住旧线的一小截（重叠 30%） | `RT-DUP-01` 要 80% 才报 |
| 旧段端点被推了一点，两段刚好错开一个线宽 | 垂距超 1.5mil，判不了共线 |
| 改了网络名，新线落在**别的网络**的旧线位置 | 报了也是 `FAB-SHORT`，等烧板才发现 |

三者同一个动作特征：**该删的旧段没删**。几何看不出动作，日志看得出。

**记账三件套**

```bash
# 1) 布线前记基线（per-net primitiveId + 几何）
easyeda pcb line-list --json > lines.pre.json
python scripts/journal.py baseline --lines lines.pre.json -o journal.json

# 2) 每画/删一段记一笔（id 取 line.create / line.delete 的返回值）
python scripts/journal.py record --journal journal.json --net VDD --delete 101 --add 301,302

# 3) 收尾对账（并进 check.py）
easyeda pcb line-list --json > lines.post.json
python scripts/journal.py verify --journal journal.json --final lines.post.json
python scripts/check.py snapshot.json --journal journal.json
```

**两条判据**

| 规则号 | 判据 | 默认级别 | 说明 |
|---|---|---|---|
| `RT-JRN-05` | 账本声明删掉的 id 在最终导出里还在 | FAIL | 旧段没删就画了新的 —— 叠画的唯一硬证据 |
| `RT-JRN-06` | 某网络的 id 集合变了，但没有对应的记账 | WARN | 删的没登记 / 加的没登记 |

**为什么必须按 id 比，不能按段数比**

EDA 会在交点处把线切开：调 200 次 `line.create` 可能得到 202 段；一段声明新增的线也可能被切成两个 id。所以：

- 段数 ≠ 操作数，用段数核对**必然误报**；
- primitiveId 是稳定的：声明删的 id 还在，就是没删；声明加的 id 变成两个，是切段。

**切段自动豁免**（`journal_cover_ratio`，默认 0.9）。消失的 id 若仍被最终铜覆盖 ≥90%，或新增的 id 落在基线铜的 90% 范围内，判为原生切段，只记 `RT-JRN-05` INFO，不算未记账。覆盖算法是共线投影的区间并集，不依赖段数。

**数据不足时不假装通过**

| 情况 | 行为 |
|---|---|
| 基线导出没有 primitiveId | `baseline` 直接 exit 2，不生成账本 |
| 只记了基线、没有 rounds | `verify` exit 2；`check.py --journal` 记 `RT-JRN-05` UNKNOWN |
| 最终导出没有 primitiveId | `verify` exit 2（缺 id 就核不了旧段） |
| 快照里走线无 id | `check.py` 记 UNKNOWN |

**两条纪律**（属于流程，不属于判据，但没它们判据就形同虚设）：

1. **改网络 = 先删后画。** 不许 `line.modify` 直接改 net，也不许把新线叠在旧线上。删之前先 `journal.py ids` 查出旧段 id 并 `record`。
2. **动一次记一笔。** 不记账的段即使几何完全干净，也无法证明是本流程画的；`RT-JRN-06` 就是为这件事留的。

`examples/journal.rounds.json` + `eda-export.lines.after.json` 账平；`eda-export.lines.overlap.json` 配同一账本 → `RT-JRN-05` FAIL；`journal.rounds.forgot.json` 配 `after` → 三条 `RT-JRN-06` WARN；同账本配 `eda-export.lines.split.json` → 切段被豁免，只出 INFO。

## 10. 布线自检清单

1. 每个网络的线宽是否来自 `rules.py`（而不是拍的）？
2. 电源/地环路面积是否最小，去耦是否在负载之前？
3. 关键信号（时钟、差分、复位、模拟小信号）是否优先、最短、有完整参考平面？
4. 是否有直角/锐角、悬空线头、自环、孤铜？
5. 跑过 `check.py` 之后，`RT-DUP-01 / RT-STUB-02` 是否为 0？`RT-LOOP-03 / RT-DETOUR-04` 命中处是改了还是登记进 `allow` 了？
6. 布线前记了基线吗？每个 `line.create` / `line.delete` 都记账了吗？`journal.py verify` 是账平（`RT-JRN-05` 无 FAIL、`RT-JRN-06` 无 WARN）吗？
7. 相邻层是否正交，3W 是否满足？
8. 差分对是否对称、等长、参考平面连续？
9. 平面分割宽度是否按电位差取值，是否有跨分割的高速信号？
10. 过孔尺寸与板厚比例是否合规，BGA 下是否 12mil 且盖阻焊？
11. 测试点是否覆盖每个网络，位置是否可探？
12. 丝印是否压焊盘、极性是否可辨？
