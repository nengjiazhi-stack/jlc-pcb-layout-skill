# 布局规范（Layout Rules）

> 出处标注：`TY-` = 华为 Q/DKBA-Y004-1999《印制电路板（PCB）设计规范》/ 同源 QMD-J001-2009；`EM-` = 艾默生 TS-S0E0202003 V2.0《PCB 工艺设计规范》/ 同源 2004 版；`BELL-` = 上海贝尔 ED02《PCB 设计规范》章节号；`ASUS-` = 华硕 MT-8-2-0037 Rev1.70 项次。
> 数值真源在 `assets/constraints.json`，本文是它的可读版本与条文解释。

## 1. 板框、原点与坐标系

| 项 | 要求 | 出处 |
|---|---|---|
| 坐标原点 | 单板左边与下边延长线交点（左下角）；或左下角第一个焊盘 | TY-6.1.4 |
| 板框线宽 | 通常 10mil 绘制 | BELL-4 |
| 板角 | R 型倒角，一般 R=φ5mm，小板可调 | TY-6.1.4 / EM-5.10.2 |
| 布线区 | 距板边应 > 5mm（含器件与铜箔） | BELL-3 / BELL-4 |
| 尺寸上限 | 多层板 ≤ 513.08 × 454.5mm（贝尔产能口径，仅作参考） | BELL-4 |
| 板厚公差 | ±10%（0.8/1.0/1.2/1.6/2.0/2.5/3.0/3.5mm 常用档） | EM-5.10.1 |

> 在嘉立创EDA里，板框必须画在 `BOARD_OUTLINE`（layer id = 11）层，且**用折线/多边形**画——`pcb_PrimitiveLine.create` 不适用于板框层。

## 2. 栅格

| 场景 | 栅格 | 出处 |
|---|---|---|
| IC 布局 | 50 ~ 100 mil | TY-6.2.4.6 |
| 小型表面贴装器件 | ≥ 25 mil | TY-6.2.4.6 |
| 纯通孔板 | 50 mil | 惯例 |
| 公制间距件（0.5/0.8mm pitch） | 不吸栅，保留原生子栅 | 实践（硬吸栅会让焊盘偏离走线） |

**规则**：吸栅只对"本体原点"生效，对已锁定的结构件和公制连接器不生效。

## 3. 板边净空（分层带，按件取最大适用值）

| 带 | 距板框 | 适用对象 | 严重度 |
|---|---|---|---|
| 制造地板 | 20 mil (0.5mm) | 任意器件本体 + 焊盘必须在框内 | FAIL |
| 铜到 V-CUT 边 | 30 mil (0.75mm) | 所有走线与铜箔 | FAIL |
| 铜到铣槽边 | 12 mil (0.3mm) | 所有走线与铜箔 | FAIL |
| 通用默认 | 40–100 mil (1–2.5mm) | 非连接器件本体 | WARN |
| 轨道/夹具边 | 197 mil (5mm) | 波峰焊/传送轨道夹持边上的器件外侧 | WARN |
| SMD 文字框到板边 | 100 mil | 板边为非夹持边时 | WARN |
| SMD 文字框到夹持边 | 150 mil | 板边为 SMT 夹持边时 | WARN |

出处：EM-5.4.12（轨道边 5mm）、EM-5.5.1（V-CUT 0.75mm / 铣槽 0.3mm）、BELL-3（布线区 5mm）、ASUS-2（100/150mil）。
边缘连接器豁免"内推"，但**焊盘必须全部在框内**；V-CUT 无法留 5mm 时用工艺边补偿，器件到 V-CUT ≥ 1mm（EM-5.4.12）。

## 4. 机械件优先（P0）

布局第一趟只做一件事：把连接器、安装孔、定位孔、面板件放到结构图给的位置，然后 **lock**。

1. **有结构图就照图逐字写坐标**，不要自己推断。
2. 无图时的回退：连接器贴边（本体最外沿距板框 ≤20mil）、开口朝板外、旋转只取 0/90/180/270。
3. 安装孔 keep-out 按紧固件参数化，不是常数：

| 螺钉 | 安装孔 | 禁布圆 |
|---|---|---|
| M2 | 2.4 ±0.1mm | φ7.1mm |
| M2.5 | 2.9 ±0.1mm | φ7.6mm |
| M3 | 3.4 ±0.1mm | φ8.6mm |
| M4 | 4.5 ±0.1mm | φ10.6mm |
| M5 | 5.5 ±0.1mm | φ12.0mm |

（EM-表5；自攻螺钉 ST2.9/ST3.5/ST4.2 对应 3.1/3.7/4.5mm 孔径、φ7.6/9.6/10.6mm 禁布）

4. **机械定位孔**（贝尔口径）：φ3.0mm，非金属化，孔心距板边 5.08mm；距最近通脚焊盘 ≥7.62mm(300mil)，距 SMD 器件本体外框 ≥5.08mm(200mil)。外层禁铜 φ9.0mm，内层禁铜 φ4.80mm，阻焊开窗 3.50mm。
5. **工具孔**（华硕口径）：长边两个，孔心距板边 (200,200)mil，成品孔 φ160 +4/-0 mil。

## 5. 功能分区与信号流向

**基本原则**（TY-6.2.4）：

- 先大后小、先难后易：核心器件与重要单元电路优先；
- 按主信号流向排布（BELL 图：连接器 → 高速区 → 中速区 → 低速区，模拟区单独用**地隔开**）；
- 高电压大电流与小电流弱信号**完全分开**；模拟与数字分开；高频与低频分开，高频器件间隔要充分；
- 相同结构电路采用"对称式"标准布局；
- 均匀分布、重心平衡。

**BELL 的分区实践**（BELL-13）：高速与对外接口的器件尽量靠近连接器；数字与模拟区用地隔开；I/O 处频率由高到低的排列顺序是 `Fast → Mid → Slow`（反过来是错误做法）。

**电源**：电源输入/变换件成块放板边或角落，功率流向从输入连接器朝板内单向推进（输入 → 保护 → 变换 → 输出电容 → 负载），不要来回折返。

## 6. 就近原则（这几颗器件的位置比美观重要得多）

| 器件 | 距离要求 | 出处 |
|---|---|---|
| IC 去耦电容 | 2 层板：距 IC 电源脚 50–100mil，硬上限 150mil；4 层以上：≤250mil，但过孔必须压在 pad 旁/贴 pad（横向距离由安装回路电感让位） | TY-6.2.11 / 实践修订 |
| 串联匹配电阻 | 距**驱动端** ≤500mil（不是接收端） | TY-6.2.13 |
| 端接电阻/RC | 放**接收端**（多负载时放最远端） | TY-6.2.13 |
| 晶振 + 两只负载电容 | 晶振体中心距 MCU 振荡脚 ≤300mil（理想），绝不 >500mil；两电容夹在晶振与 MCU 之间、对称布置，偏差 ≤50mil；晶振下方铺地、不走线 | TY-7.2.2 |
| 反馈取样电阻 | 紧贴稳压器 FB 脚，走线远离 SW 节点 | 惯例 |
| 电源入口 bulk 电容 | 距输入连接器/稳压器输出 ≤500mil | 惯例 |

去耦电容的**数量**不要机械地对齐电源脚数量——按 PDN 目标阻抗决定；但"某个大电流电源脚周围没有任何去耦电容"是必须报出来的提示（TY-6.2.11）。

## 7. 热

| 要求 | 数值 | 出处 |
|---|---|---|
| 温敏器件（电解电容等）距自身温升 >30℃ 的热源（风冷） | ≥2.5mm | EM-5.2.4a |
| 同上，自然冷却 | ≥4.0mm | EM-5.2.4b |
| 发热密度超过该值须加散热措施（散热网/汇流条/散热器） | 0.4 W/cm³ | EM-5.2.7 |
| 发热元件均匀分布 | — | TY-6.2.6 |
| 电解电容、晶振、传感器不在稳压器气流下游 | — | EM-5.2.2 |

高热器件优先放**出风口或利于对流**的位置，较高的元件放在出风口但不阻挡风路；散热器放置考虑对流方向（EM-5.2.1~5.2.3）。多层板内层可用辅助铜箔 + 电镀通孔帮助散热（EM-5.2.8）。

**例外**：稳压器自己的陶瓷输入电容、续流二极管、开关管这几颗**不受**热 keep-out 约束——它们要贴紧（回路面积优先于热散开）。

## 8. 器件间距

| 场景 | 最小间距 | 推荐值 | 出处 |
|---|---|---|---|
| 同种贴片器件 | ≥0.3mm | — | EM-5.4.11 |
| 异种贴片器件 | ≥ 0.13×h + 0.3mm（h 为邻件最大高度差） | — | EM-5.4.11 |
| 只能手工贴片的器件之间 | ≥1.5mm | — | EM-5.4.11 |
| SMD ↔ SMD（同侧） | ≥0.5mm | 0.75mm | DFM 通用 |
| SMD ↔ 通孔件 | ≥1.0mm | 1.5mm | DFM 通用 |
| 通孔件 ↔ 通孔件 | ≥1.5mm | 2.0mm | DFM 通用 |
| PLCC / QFP / SOP 相互之间 | ≥2.5mm | — | 通用 SMT |
| PLCC / QFP / SOP ↔ Chip / SOT | ≥1.5mm | — | 通用 SMT |
| SMT 焊盘边到边 | ≥0.15mm | — | IPC-7351B Class 2 |
| SMT 焊盘边到边（0201 / 01005） | ≥0.12mm | — | IPC-7351B |
| 通孔焊盘中心距 | ≥0.3mm | — | IPC-7351B |
| 器件本体 → 板边 | ≥2.0mm | 3.0mm | DFM 通用 |
| 器件本体 → 拼板导轨/夹持边 | ≥3.0mm | 5.0mm | DFM 通用 |
| BGA 四周禁布 | 3mm（最佳 5mm） | 5mm | EM-5.4.10 / TY-6.2.10 |
| 贴片焊盘外侧 与 相邻插装件外侧 | >2mm | — | TY-6.2.10 |
| 压接件周围 | 5mm 内不得有插装件，焊接面 5mm 内不得有贴装件 | — | TY-6.2.10 |
| 经常插拔的器件/板边连接器周围 | 3mm 内尽量不布 SMD | — | EM-5.4.6 |
| 通孔回流焊器件焊盘边缘 | 距传送边 >10mm，非传送边 >5mm | — | EM-5.4.18f |
| 通孔回流焊器件本体之间 | >10mm | — | EM-5.4.18e |

> **取严原则**：同一对器件同时命中多条时取**最大值**。上表 DFM 通用口径与 EM/TY 口径冲突时，以**你的 PCB/SMT 厂家能力表**为最终依据——各家不一样，投板前必须确认。

## 9. 朝向与极性

- 同类型插装元件在 X 或 Y 方向**朝一个方向**；同种有极性分立件也保持一致（TY-6.2.5）。
- 表贴件布局注意**焊盘方向一致**，利于装焊、减少桥连（BELL-3 第 13 条）。
- **IC 的 1 脚统一朝同一角落**（通常左上）；同封装的 IC 不允许出现多种 1 脚朝向（检验/调试口径）。
- **极性标识方向全板不超过 2 个**；出现 2 个时必须**互相垂直**（相差 90°），不允许任意角度。
- 丝印字符方向统一（同类器件位号同向），不允许出现向右或向下倒着的字符。
- Chip 器件长轴尽量与最近的板边平行，贴边放置时长轴垂直于板边。
- 大于 0805 的陶瓷电容尽量靠近传送边或受力较小区域，轴向尽量与进板方向平行；**尽量不用 1825 以上尺寸**的陶瓷电容（EM-5.4.5）。
- 较轻的二极管、1/4W 电阻：轴线与波峰焊方向**垂直**，防止单端先焊造成浮高（EM-5.4.28）。
- 多个引脚在同一直线上的器件（连接器、DIP、T220）：轴线与波峰焊方向**平行**（EM-5.4.27）。

## 11. 摆放顺序（P0 → P6，必须按序执行）

**这是本 skill 对"按规范摆件"的硬要求：前一档没锁定，不许进下一档。** 顺序来自 TY-6.2.4「先大后小、先难后易」+ BELL-13 分区实践，机器可读版本在 `assets/constraints.json → placement.placement_order`。

| 档 | 摆什么 | 约束 |
|---|---|---|
| **P0** | 机械锁定件：连接器 / 安装孔 / 定位孔 / 面板件 / 结构件 | 照结构图逐字写坐标 → **lock**；无图时贴边（本体外沿距板框 ≤20mil）、开口朝板外、旋转只取 0/90/180/270 |
| **P1** | 功率与热源：电源入口、变换器、功率器件、电感 | 靠输入边 / 出风口；热源分散不扎堆；功率流单向推进（输入→保护→变换→输出电容→负载），不折返 |
| **P2** | 核心 IC 与高速 / 高频器件 | 靠近它服务的接口；数字与模拟分区，高频器件间隔充分 |
| **P3** | 就近器件：去耦电容 / 串联匹配电阻 / 晶振 + 负载电容 / 反馈取样 | 见 §6 就近原则表，全部是硬距离；**这一类比美观重要得多，不许为了对齐把它们拉走** |
| **P4** | 敏感小信号与模拟前端 | 与数字 / 功率区用地隔开，远离热源与电感 |
| **P5** | 其余阻容与离散件 | 同类同封装朝向统一；阵列对齐；吸栅（IC 50–100mil，小型 SMD ≥25mil） |
| **P6** | 测试点 / MARK 基准点 / 丝印 | MARK ≥3 个非对称；测试点焊盘 ≥24mil、中心距 ≥60mil |

**P3 是违规高发区。** 摆 P5 时如果为了"阵列好看"把去耦电容从 IC 电源脚旁挪走，直接违反 §6 —— 裁决顺序是**电气 > 结构 > 制造 > 整齐**（见 `routing-aesthetics.md`）。

## 12. 器件高度与三维干涉

| 项 | 要求 | 出处 |
|---|---|---|
| 标准贴片设备高度上限 | 25mm（超出需手工放置或换封装） | DFM 通用 |
| 高器件（≥6mm）与矮件间距 | ≥2mm | DFM 通用 |
| 贴片顺序 | 先放矮件，后放高件 | 自动化口径 |
| 高器件与回流/波峰方向 | 高件不挡在矮件的上风向/来料侧（阴影效应） | EM-5.4.x |
| 靠近板边的 TO-220 类（7805 / 7812） | 卧式设计，防止受外力折断引脚或起铜皮 | 通用装配 |
| 金属外壳晶振 | 卧式 + 加胶固定（防震） | 通用装配 |
| 器件装入壳体后 | 最高处与盒体留间隙，不得受压 | 整机装配 |

**注意**：`height_mm` 不在默认快照里。缺这个字段时 `check.py` 会输出 `PL-HEIGHT` 的 **INFO 明说"未判定"**，**别当成通过**——要判定就得从封装库或 BOM 把高度补进 snapshot。

## 13. 机械约束

| 项 | 要求 |
|---|---|
| 重心 | 器件重心接近板几何中心，**偏移量不得超过半板尺寸的 25%**（即不得落入板边缘 1/4 区域） |
| 重件（变压器、大电感） | 靠近支撑点（螺丝孔）放置，防振动脱落 |
| 波峰焊板 | 紧固件安装孔与定位孔应为**非金属化孔**；需接地时用分布接地小孔连到地平面（TY-6.2.8） |
| 壳体 | 高件装入后与盒体留间隙，不受压应力 |
| 禁布区 | 螺丝孔、卡扣、外壳筋位按结构图设 keep-out，P0 阶段就锁 |

## 14. 可维护性与可测试性

| 项 | 要求 |
|---|---|
| 小元件周围 | **不能放大元件**——否则烙铁/热风枪下不去（TY-6.2.7） |
| 需调试的器件 | 周围留足操作空间（≥3mm），并加丝印说明 |
| 外接插座 | 放在易于插拔的位置；选型和颜色能区分，防插错 |
| 插拔件周围 | ≥3mm 净空（EM-5.4.6） |
| 关键网络 / 芯片附近 | 留测试点与地孔，便于示波器探针接地 |
| 兼容/可选焊器件 | 附近加文字备注并说明理由 |

## 15. 基准点（MARK）补充

在 EM-5.7.2 口径（φ40mil，2 个对角）之上，通用 SMT 设备口径更严：

| 项 | 要求 |
|---|---|
| 数量 | **每板/拼板 ≥3 个**：2 个对角 + 1 个定向 |
| 布局 | **非对称**，防止 180° 转错；跨距尽量拉大到板对角 |
| 焊盘直径 | 1.0mm（可接受 0.5–2.0mm） |
| 阻焊开窗 | 2 × 焊盘直径 |
| 与其它特征间距 | ≥3mm |
| 拼板 | 基准点放在工艺边上 |

## 16. 车规补充（`board.automotive = true` 时才判定）

| 项 | 要求 |
|---|---|
| 电感间距 | ≥5mm，且相邻电感**轴向互相垂直**（防磁场耦合） |
| 热敏器件（晶振 / EEPROM / 传感器） | 离热源 **≥25mm**，且置于气流**下游**（不是上游） |
| 散热焊盘 | 必须十字花（thermal relief）连接，臂宽 **≥0.4mm**，否则回流时散热过快虚焊 |
| 敏感电路 | 距安装孔边缘 ≥5mm |
| 高压爬电 | 高压线与低压线间距 ≥0.5mm/kV；电源平面边界内缩 ≥1mm |
| 大电流（>5A） | 每连接点并联过孔 ≥4 个 |

## 17. 布局自检清单（按顺序打勾）

1. 板框、圆角、安装孔、定位孔与结构图一致，已 lock（P0）；
2. 每颗器件本体与焊盘都在板框内，边距落在正确分层带；
3. 电源块靠输入边、功率流单向不折返（P1）；
4. 高速/接口件靠连接器，模拟区与数字区有明确边界（P2/P4）；
5. 每颗 IC 的每个电源脚都有去耦电容在阈值内，且电容有独立的 GND 回流通道（P3）；
6. 晶振位置 + 两只负载电容对称 + 下方无走线（P3）；
