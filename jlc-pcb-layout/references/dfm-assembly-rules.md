# 工艺与组装规则（DFM / Assembly）

> 出处：`EM-` 艾默生《PCB 工艺设计规范》，`ASUS-` 华硕《PCB Layout Rule》Rev1.70，`BELL-` 上海贝尔。这一份决定"板子能不能做出来、好不好贴装"。

---

## 1. 过板方向（一切装配规则的基准）

**SMT 回流**：PCB 以**短边**过回流炉，长边为输送带夹持边（ASUS-1）。
**DIP 波峰**：I/O Port 朝前过波峰炉，与 I/O **垂直**的两边为夹持边（ASUS-1）。
**金手指**：SMT 时金手指边与夹持边垂直；DIP 时与夹持边一致（ASUS-1.1）。

所有"距夹持边"的要求都以这条为前提。若板子可从两个方向过板，用双箭头进板标识（EM-5.4.2）。

## 2. 器件文字框（courtyard）

| 要求 | 数值 | 出处 |
|---|---|---|
| 文字框内缘距"器件最大本体最外缘或 PAD 最外缘" | ≥10mil（即双边 ≥20mil） | ASUS-5 |
| 文字框尺寸 | 长 ≥ Lmax+20，宽 ≥ Wmax+20（Lmax/Wmax 取公差上限） | ASUS-5 |
| 文字框线宽 | ≥6mil | ASUS-6.1 |
| 极性标记线宽 | ≥12mil | ASUS-7.2 |
| 所有器件必须有文字框 | 框外缘不可互相接触、重叠 | ASUS-6 |

极性标示惯例：QFP 用第一脚缺角；SOIC 用三角框；钽电容在极性端画粗线（ASUS-7）。

> 在嘉立创EDA里文字框对应封装的 courtyard（`COMPONENT_SHAPE` 层，id=48），画封装时就该带，布局阶段用它做不重叠检查。

| 到"左右平行板边" | ≥140mil | ASUS-10 |

| 铜箔/走线到 V-CUT 边 | >0.75mm | EM-5.5.1 |
| 铜箔/走线到铣槽边 | >0.3mm | EM-5.5.1 |

| 做 V-CUT 的板厚 | <3.5mm | EM-5.10.3 |
| 不规则拼板铣槽间距 | >80mil | EM-5.10.4 |

MLCC 应力防护：大于 0805 的陶瓷电容尽量靠近传送边或受力较小区域，**长轴平行于最近 V-CUT 线**，让分板弯折拉短轴而不是扯端头（EM-5.4.5）。

## 4. 大面积铜箔与热焊盘

| 要求 | 数值 | 出处 |
|---|---|---|
| 需过 **5A 以上**大电流的焊盘 | **不得**采用隔热焊盘（必须全连接） | EM-5.2.5 |
| 大面积铜箔上的元件焊盘 | 用隔热带与焊盘相连（热量均衡，好上锡） | EM-5.2.5 |
| 0805 及以下片式元件两端焊盘 | 散热对称；焊盘与导线连接部宽度 ≤0.3mm | EM-5.2.6 |
| 搪锡锡道宽度 | ≤2.0mm | EM-5.2.7 |
| 锡道边缘间距 | >1.5mm | EM-5.2.7 |
| PTH 接大铜箔（零件面及内层） | 用 Thermal Relief，或用"过锡炉前方 180° 可直连、后方 180° 需间隔 ≥60mil" | ASUS-9 |
| 绕线盘 PAD / 文字框 | φDrill/φPAD = 80/120mil，文字框 φ734mil | ASUS-7 |

立碑（tombstoning）根因就是两端热容不对称 —— 0402 及以下的两 pad 件，避免一端接大铺铜另一端接细线。

## 6. 基准点（Fiducial）

| 项 | 艾默生口径 | 贝尔口径 |
|---|---|---|
| 焊盘直径 | φ40mil ±1mil | 1.60mm（标准板）/ 1.0mm（高密度） |
| 阻焊开窗 | φ80mil | 3.20mm / 2.20mm |
| 无铜区 | — | 3.40mm / 2.40mm |
| 保护环 | 外径 φ110mil、内径 φ90mil、线宽 10mil | — |
| 距板边 | ≥5mm | 距板边/定位孔 ≥7.5mm |
| 数量 | ≥2 个，成对角 | ≥2 个，成对角 |
| 位置 | 顶层与底层都要有 | 顶层与底层表面焊盘 |
| 其它 | 基准点范围内不得有走线与丝印；需拼板时每个单元板尽量保留 | 必须有相同 X 或 Y 坐标；必须加阻焊 |

（EM-5.7.1~5.7.5，BELL-8）

有表贴器件的 PCB 板对角至少两个不对称基准点（EM-5.7.1）；铝基板/厚铜（≥3OZ）基准点设置为 φ80mil 铜箔上开 φ40mil 阻焊窗（EM-5.7.3）。

## 8. 丝印与标注

- 所有器件、安装孔、定位孔都要有对应丝印标号，安装孔用 H1、H2…Hn（EM-5.8.1）；
- 字符从左至右、从下往上；极性件在每个功能单元内方向一致（EM-5.8.2）；
- 器件焊盘、需要搪锡的锡道上**不得有丝印**；器件位号不得被安装后遮挡；丝印不得压在导通孔/焊盘上（EM-5.8.3）；
- 丝印间距 >5mil；丝印字符与 BOM 标识符一致（EM-5.8.10）；
- 板面留条形码位置（42×6mil 框）时注意不被器件遮挡（EM-5.8.6）；
- 板名、日期、版本号丝印位置明确醒目（EM-5.8.7）；
- 保险丝附近 6 项标识齐全；危险电压区 40mil 虚线隔离 + 高压警示（EM-5.9.1/5.9.2）；
- 顶层（第一层）是元件面且为正图形，焊接面为反图形（BELL-25）。

## 9. 可制造性快速自检

1. 板子能过炉吗（短边进、I/O 朝前、夹持边 5mm 内无高件）？
2. 每颗器件有 courtyard，且互不重叠（≥0.3mm）？
3. V-CUT / 邮票孔与器件、铜箔的距离达标？
4. 大电流焊盘没有误用隔热焊盘？小片式件两端热容对称？
5. BOTTOM 面器件重量/面积比合规（如果要两次回流）？
6. 基准点数量、尺寸、阻焊窗、保护环、距边距离合规？
7. 测试点尺寸/间距/到板边距离合规，覆盖面够？
8. 丝印不压焊盘、极性可辨、位号与 BOM 一致？
9. 拼板方式与工艺边决定了吗？V-CUT 数量是否 ≤3 条？
10. 高件是否避开了夹具与吸嘴路径？
