# 布线美观：把"整洁"拆成可验收项

> 本文件回答一个问题：评审时有人说"这块板不够整齐"，到底在说什么，能不能变成可测的判据。
>
> 结论先行：**"美观"本身不可验收，但它底下的 5 个物理量可以**——角度、对齐、间距一致性、线宽连续性、图元从属关系。凡是落不到这 5 项上的"好看"，都是个人偏好，不该写进规范。

---

## 0. 拆解：观感 → 物理量 → 查法

| 观感描述 | 实际对应的物理量 | 查法 |
|---|---|---|
| "线条很乱" | 拐角角度分布、同向平行段比例、换层次数 | 逐层看拐角统计，或 `check.py` 的直角/锐角检查 |
| "参差不齐" | 器件中心坐标是否落在基准线上 | 导出坐标，按功能块分组看 x/y 众数 |
| "疏密不均" | 同功能器件中心间距的离散度 | 算间距标准差，或直接看 courtyard 间隙分布 |
| "粗细不一" | 同网络线宽的最大/最小比 | `check.py` 同网络线宽一致性检查 |
| "看不清" | 丝印字高、间距、是否压焊盘、方向种类数 | 图层可见性逐项核 |

## 1. 三条理由，证据强度差很多

"走 45° 不走 90°"这句话，被引用了三十年，但支撑它的理由分三个等级。**混用会让规范失去说服力**——工程师一旦发现你在用假物理理由，整份规范都不信了。

### 1.1 锐角/尖角（<90°）：真问题，必须禁

- **电流密度集中**：铜箔在锐角处有效宽度收窄，载流能力按最窄处算，大电流路径上会形成热点。
- **酸角陷阱**：蚀刻液滞留在尖角缝隙里持续咬铜，导致线宽不足甚至开路。这在早期工艺上是实打实的良率杀手；现代板厂的蚀刻控制改善很多，但**尖角在 DFM 检查里仍然是被挑出来的项**。
- 结论：**锐角无条件禁止**。这一条不需要讨论。

### 1.2 90° 直角：二阶电气问题 + 主要靠工艺余量和观感

电气上确实有影响，但要说清量级：

- 拐角处有效线宽约为直段的 √2 倍（1.414×），特性阻抗随之下陷。PCBGOGO 给的算例：6 层 A-1080 叠层、50Ω 需 3.97 mil 线宽，直角处等效 5.61 mil，阻抗掉到约 **42.6Ω**。
- 但**单个拐角的影响远小于其它误差源**。21ic / Andwin 的原文自己承认：这个影响"相对于导线与参考平面高度的偏差、蚀刻过程中线宽线距均匀性的变化、板材介电常数随频率的变化，甚至过孔寄生参数所带来的影响都要小得多"。
- 累积效应才是真问题：等长绕线叠十几二十个拐角后，反射与延时误差开始不可忽略。HDMI 2.0（18 Gbps）这一档，直角绕线已经不合格。

**诚实版本的说法**：直角在低频低速板上不会让板子坏掉，禁它的主要理由是①累积效应在高速绕线里不可忽略 ②工艺余量 ③观感。Dave Jones 的 PCB Design Tutorial 说得更直白：直角"不会产生可测量的 EMI 或其它问题，避免直角的原因更简单——它就是不好看，而且可能有制造上的影响"。

> 写规范时用这句话比编 EMI 理由更有用。工程师会服，因为他验过。

### 1.3 45° 是行业惯例，不是物理定律

- 45° 的统治地位来自 EDA 工具的默认约束和早期手工贴图（taped artwork）时代的美学惯性，不是因为 45° 比圆弧"电气更好"。
- 实际上圆弧的阻抗过渡最平滑。但圆弧在高密度板上**修线代价高、占空间**，所以工程上的通行口径是：
  - 普通数字/模拟信号 → 45° 折线
  - RF / 微波传输线 → 圆弧，或"45° 外斜切"
  - USB3.1 / HDMI 2.0 这类高速差分 → 可以考虑圆弧
- 别把"必须走圆弧才专业"当规范，那是另一头的教条。

## 2. 九条可量化判据

以下每条都能落到数字或二元判定，可以直接写进评审表。

| # | 判据 | 出处 / 说明 |
|---|---|---|
| 1 | 拐角内角 ≤135°（即转折角 ≥45°），**禁止 ≤90° 的转折**；大电流铺铜拐角同样处理 | TY-6.5.6-12；铺铜拐角用两个 45° 替代一个 90° |
| 2 | 45° 绕等长时：拐角处走线段长 ≥**1.5×线宽**；绕线之间的间距 ≥**4×线宽** | 间距不足时线间寄生电容让信号"抄近路"，等长失准 |
| 3 | 同网络线宽全程一致。必须变宽（进 BGA/细间距）时用锥形渐变，不做台阶突变 | TY-6.5.x 图示；突变 = 阻抗不连续 |
| 4 | 平行走线中心距 ≥**3W**（约 70% 电场不耦合）；敏感/高速网络之间插入接地隔离线 | 3W 规则 |
| 5 | 相邻信号层走线方向正交（一层横一层竖） | 降低层间串扰，也让图面更有秩序 |
| 6 | 走线从焊盘**中心**进入，不从边角擦入；不"刚好碰到"焊盘 | 便于软件判定连接；间距最充裕；观感也对 |
| 7 | 一根线不拼（不把多段短跟踪首尾相接）。要延长就删掉重画 | 拼接线后期无法顺畅编辑 |
| 8 | 无死铜（未连任何网络的铜）、无悬空线头 | 死铜是天线；悬空线头同理 |
| 9 | 丝印：单一阅读方向（左→右、下→上），同功能器件位号落在相同相对位置，极性标记方向统一 | PC 5.7.x / TY-6.2.5 / NexPCB |

## 3. 轴线与阵列：量产板的"整齐"是从哪来的

看过几十块量产板会发现，"整齐"不是每条线都笔直，而是**同组对象共享基准**。

- **建立基准线**：同类接口、重复通道、非关键阻容，在横纵方向各定一条基准线，器件中心对齐到线上。
- **重复通道一致**：多路相同电路（多路 LED 驱动、多路 ADC 前端）的走线拓扑、线宽、过孔位置、丝印位置应逐路相同。**一致性本身就是可读性**。
- **位号与标记同步对齐**：位号、极性、1 脚标记沿同一条轴线排布，同类器件放在相同相对位置。
- **板边与固定孔服从结构，不服从对齐**：接口、连接器、安装孔的位置由外壳决定，不允许为排齐而移动。
- **定位孔要不对称**：PC 5.12.4 明确要求定位孔位置在 PCB 上不对称，防止装反。
- **基准点至少两个且不对称**：PC 5.7.1。

### 对称性条款（来自通用规范原文）

- TY-6.2.4.4：相同结构电路部分，尽可能采用"对称式"标准布局。
- TY-6.2.4.5：按均匀分布、重心平衡、版面美观的标准优化布局。
- TY-6.2.5：同类型插装元器件在 X 或 Y 方向上应朝一个方向放置；同类型有极性分立元件也应力争保持一致，**便于生产和检验**。

注意最后半句的落点：**方向一致的目的是生产与检验效率，不是好看**。这个理由比"美观"硬得多，讲这个更能说服人。

## 4. 美观与性能冲突时怎么裁

这是实战里最常吵的地方。给一个明确的优先级，减少来回：

```
电气约束（载流/阻抗/回流/间距）
  > 装配与结构约束（外壳/插合/维修空间）
    > 制造约束（最小线宽/间距/阻焊桥）
      > 图面整齐与对称
```

**不允许的交换**：

- 为对齐把去耦电容从 IC 引脚旁拉走 → 违反去耦环路优先。去耦电容应该贴在引脚—地—返回引脚形成的最小环路上，不能为了跟其它电容排成一列而拉远。
- 为 45° 强行绕线增加路径长度 → 低速线也吃亏，高速线更是不行。
- 为对称割地 → 地的完整性优先于视觉对称。
- 全板强制同宽同距 → 不同网络有不同用途，线宽应随用途变（电源宽、信号窄、差分按阻抗算）。

**允许的例外**：必要的逃线、差分补偿、阻抗匹配结构、散热铜皮。这类"不整齐"要记录位置、网络和保留理由——按 TY 的口径，"原来就这样""自动布线结果"不是技术依据。

## 5. 五个常见误区

| 误区 | 为什么错 |
|---|---|
| "全板 45° 才算专业" | RF 和高速差分用圆弧更好；强行全 45° 可能拉长路径 |
| "DRC 零报错就是布线完成" | DRC 只证明启用的规则被满足，不证明整洁、不证明性能 |
| "直角会产生严重 EMI" | 单个直角的影响小于参考面偏差和蚀刻误差。用这个理由会被当场反驳 |
| "线越短越好看" | 点对点直连在初看时显得高效，但占用了其它层走线通道，整体反而更挤 |
| "美观是主观的没法查" | 本文第 0 节已经把它拆成 5 个可测量，能查 |

### 7.1 三条检查为什么这么设阈值

**对齐**用的是"多数服从"而不是"全等"。器件本来就可能交错排两排（有意为之），一刀切判"不共线"会满板误报。所以口径是：同一行里 ≥60% 已经在 ±12mil 内、又有个别掉队，才算参差不齐。判出来的基准线取组内**中位数**，不取第一条线的坐标——否则一条错位的线会把整组带歪。

**间距**用变异系数（标准差/均值）而不是绝对差。间距 100mil 的组差 20mil 是 20%，间距 400mil 的组差 20mil 只有 5%，后者其实更整齐。

**角度**容差 4° 而不是 0°。EDA 导出的坐标常因焊盘中心取整出现亚度偏差（比如 5mil/110mil ≈ 2.6°），那不是"任意角度走线"。真正要抓的是 30°、60° 这种明显没落栅格的段。

### 7.2 怎么跑

```bash
python scripts/check.py examples/snapshot.aesthetics.json --min-severity WARN
```

预期输出（这是故意做的反面样例，别当成"检查器坏了"）：

```
[WARN] AEST-ALIGN   C 组(0402) 第行   5 颗本应共线，C5 偏离基准线 22mil
[WARN] AEST-PITCH   C 组(0402) 第行   相邻中心距离散：80~200mil，变异系数 43%
[WARN] AEST-ROT     R1                旋转 37° 不是 90° 整数倍
[WARN] AEST-ANGLE   net SIG1          1 段走线角度偏离 45° 栅格（最大偏差 11°）
```

同一份文件里的 `C1~C3`（y=500）与 `C4~C6`（y=560）构成了一个**不该报错**的交错双排——检查器对它们保持沉默，这是 7.1 那条阈值口径的验证点。
