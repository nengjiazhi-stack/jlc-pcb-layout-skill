# 叠层设计与阻抗

> 出处：`TY-` 华为/通用规范，`EM-` 艾默生工艺规范（表7 层间介质厚度），`BELL-` 上海贝尔（叠层排列图）。

---

## 1. 先定层数

### 1.1 Pin 密度法（TY-6.3.1）

`Pin 密度 = 板面积(in²) / (板上管脚总数 / 14)`

| Pin 密度 | 信号层 | 总层数 |
|---|---|---|
| >1.0 | 2 | 2 |
| 0.6–1.0 | 2 | 4 |
| 0.4–0.6 | 4 | 6 |
| 0.3–0.4 | 6 | 8 |
| 0.2–0.3 | 8 | 12 |
| <0.2 | 10 | >14 |

命令：`python rules.py layers --pins 320 --area-mm2 2500 --clock-mhz 24`

> **重要校准**：这张表来自 1999 年以通孔插件为主的设计环境，现代 HDI/BGA 板实际层数常显著更低。把它当作**上限参考**，不要机械照搬——先按功能需求定（有没有完整地平面、有没有阻抗控制、BGA 要不要扇出），再用这张表做上限校验。

### 1.2 硬触发条件（TY-6.5.6.20）

时钟频率 ≥5MHz **或** 脉冲上升时间 <5ns → 必须多层板（至少 4 层）。双层板方案下，必须把一面做成完整地平面。

## 2. 叠层排列原则

**工艺优先**（BELL-5）：四层板推荐"铜箔 - 半固化片 - 芯板 - 半固化片 - 铜箔"的**对称**结构；不对称结构在压合时容易翘曲，属于"不推荐"。

**电性能优先**（BELL-6）：

- 尽量用地层/电源层把信号层**隔开**；
- 无法隔开的相邻信号层，走线方向**必须正交**；
- 电源层与地层**相邻且靠近**，中间不安排布线（TY-6.3.1.1）；
- 所有布线层尽量靠近一个平面层，优选**地平面**作隔离层。

错误示例（BELL 原图）：`clock → interconnect → Vcc → ground`（clock 与 interconnect 相邻同向）。
正确示例：`interconnect → ground → Vcc → clock/interconnect`。

## 4. 惯用叠层（4 层 / 6 层）

**4 层（最常用）**

| 层 | 用途 | 说明 |
|---|---|---|
| L1 | 信号 + GND 铺铜 | 器件面，走线尽量短 |
| L2 | **完整地平面** | 参考平面，绝对不要走线 |
| L3 | 电源平面 / 电源铺铜 | 按电源域分割，分割宽度见 §5 |
| L4 | 信号 + GND 铺铜 | 焊接面 |

**6 层（有大量高速信号）**

| 层 | 用途 |
|---|---|
| L1 | 信号（高速） |
| L2 | GND |
| L3 | 信号（次高速） |
| L4 | 电源 |
| L5 | GND（或第二电源域） |
| L6 | 信号（低速/接口） |

规则：两个电源网**不要共享同一内层**，各给独立内层（需要 6 层以上）；GND 最好覆盖 ≥2 层。

## 5. 平面分割与边沿效应

- 不同电源/地之间的分割宽度：电位差 **>12V → 50mil**；≤12V → **20~25mil**（TY-6.3.1.2.5.3A）。
- 分割要考虑高速信号回流路径完整性；回流路径被破坏时在布线层用接地铜箔包围该信号，提供地回路。
- **20H 规则**：电源层相对地层内缩 20H（H = 电源与地之间介质厚度）可把 70% 电场限制在地层边沿内，100H 可限制 98%（TY-6.5.6.19）。
- 平面层一般作电源/地参考层；不同电源层在空间上避免重叠，难以避免时中间隔地层（TY-6.5.6.17）。

## 6. 阻抗控制

### 6.1 目标值

| 类型 | 典型目标 |
|---|---|
| 单端（通用数字） | 50Ω ±10% |
| USB 2.0 全速/高速 | 90Ω ±10% 差分 |
| 以太网 / USB3 / HDMI | 100Ω ±10% 差分 |
| DDR 数据线 | 40–50Ω 单端，80–100Ω 差分（按器件手册） |

### 6.2 估算公式（IPC-2141 简化式，仅用于初选）

```
微带（外层）      Z0 = 87 / √(εr+1.41) · ln(5.98h / (0.8w + t))
带状线（内层）    Z0 = 60 / √εr · ln(4h / (0.67π(0.8w + t)))
差分微带          Zdiff = 2·Z0·(1 − 0.48·e^(−0.96·s/h))
差分带状线        Zdiff = 2·Z0·(1 − 0.347·e^(−2.9·s/h))
```

`w` 线宽、`h` 介质厚度、`t` 铜厚、`s` 差分间距（同单位）。

命令：`python rules.py impedance --type microstrip --w 0.2 --h 0.2 --er 4.3 --target 50`

**误差约 ±10%，正式值必须用板厂阻抗计算器（嘉立创下单页有阻抗计算器）或场求解器复算。** 下单时要在阻抗控制层上标注清楚（TY-6.3.1.1）。

### 6.3 敏感度排序（调参时按这个顺序动）

1. **h（介质厚度）** —— 影响最大，但一改就要换叠层，最好一开始定死；
2. **w（线宽）** —— 最常用的调节手段；
3. **εr** —— 由板材决定（FR-4 常见 4.2–4.6，随频率上升而下降）；
4. **t（铜厚）** —— 1oz 比 0.5oz 阻抗略低；
5. **s（差分间距）** —— 只影响差分阻抗。

### 6.4 阻抗线的布线纪律

- 阻抗控制网络必须**排布在阻抗控制层**上（TY-6.5.5）；
- 同一网络线宽全程一致，变宽处（BGA 出线、连接器）把不一致段压到最短（TY-6.5.6.6）；
- 阻抗线不得跨越平面分割、不得贴着板边（参考面不完整）；
- 换层时旁边补回流地过孔（差分对两个过孔一起换）；
- 差分对全程等间距，过孔处不要摊开。

## 7. 铜厚选择

| 铜厚 | 厚度 | 适用 |
|---|---|---|
| 0.5oz | 17.5µm | 极细线（<4mil）、高密度 |
| 1oz | 35µm | **默认** |
| 2oz | 70µm | 大电流（>3A）、散热、电源板 |

> 铜厚上去之后最小线宽/间距会变差（蚀刻因子），2oz 一般做不到 4mil。要改铜厚先问板厂。

## 8. 叠层自检

1. 层数依据是什么（Pin 密度 / 5-5 规则 / 阻抗需求 / BGA 扇出）？
2. 叠层是否**对称**（厚度、铜厚、介质）？
3. L2 是不是完整地平面，有没有被走线破坏？
4. 相邻信号层是否正交？电源层与地层是否相邻？
5. 介质厚度是否与板厂实际叠层一致？
6. 阻抗目标是否写进下单文件，是否标注了阻抗控制层？
7. 平面分割宽度是否按电位差取值？20H 是否做了？
